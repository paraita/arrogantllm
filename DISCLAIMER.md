# Disclaimer

Make Believe LLM is a humor project and a development mock. It does not contain, download, or run real language models. It does not perform real inference, reasoning, or embedding generation. Its answers, thinking text, token counts, embeddings, and delays are fabricated for testing and entertainment.

This project is **not a honeypot and must not be used as one**. It is not intended to deceive people into believing they are using a real model service. Do not represent its outputs, model metadata, performance, or tool calls as genuine. Marketplace metadata is informational, may be incomplete or inferred, and is clearly marked accordingly.

Use the service to test your own applications in environments where the mock nature is understood. It is not a production inference service and makes no guarantees about the accuracy or suitability of its responses.
